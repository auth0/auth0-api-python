# Common Pitfalls

1. **Do not run `ruff format .`.** CI runs only `ruff check .`. The codebase is not ruff-formatted (`ruff format --check .` reports 13 files that would be reformatted), so a repo-wide format produces a large unrelated diff. Match surrounding formatting by hand.
2. **Python 3.9 compatibility.** CI tests 3.9 and `.ruff.toml` targets `py39`. Avoid `X | Y` type unions at runtime, `match` statements, and other 3.10+ syntax. `ada-url` has separate version constraints above and below 3.10 in `pyproject.toml`.
3. **Async tests need `@pytest.mark.asyncio`.** No `asyncio_mode` is set in `pyproject.toml`, so pytest-asyncio runs in strict mode and ignores an unmarked async test. Depending on the pytest version it then fails with an "async def functions are not natively supported" message or is skipped with a warning. If a new async test fails that way or shows as skipped, check the marker first.
4. **Two dependency lists.** `pyproject.toml` + `poetry.lock` drive installs. `requirements.txt` is a hand-maintained copy that only the Snyk SCA workflow reads. Changing one without the other leaves the scan out of date.
5. **`custom_fetch` covers only discovery and JWKS.** `fetch_oidc_metadata` and `fetch_jwks` (`utils.py`) use the integrator's `custom_fetch` when set. The token endpoint calls in `get_access_token_for_connection` and `get_token_by_exchange_profile` always build their own `httpx.AsyncClient` with `options.timeout`. Do not assume a new HTTP path inherits either behaviour, pick the matching pattern deliberately.
6. **`.ruff.toml` uses deprecated top-level keys.** ruff warns that `select` / `ignore` / `per-file-ignores` belong under `[lint]`. The warning is harmless. Migrating the file is a separate change, do not fold it into unrelated work.
7. **Stale local venvs.** A hand-made venv in the working tree (anything other than Poetry's) may not have the package or dev dependencies installed. Use `poetry install` then `poetry run ...` so you test the same environment CI does.
