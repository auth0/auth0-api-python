# Common Pitfalls

1. **Do not run `ruff format .`.** CI runs only `ruff check .`. The codebase is not ruff-formatted (`ruff format --check .` reports 13 files that would be reformatted), so a repo-wide format produces a large unrelated diff. Match surrounding formatting by hand.
2. **Python floor compatibility.** The floor is the `python` constraint under `[tool.poetry.dependencies]` in `pyproject.toml`. CI tests it as the lowest matrix version and `.ruff.toml` `target-version` matches it. Avoid syntax newer than the floor. While it is below 3.10, that means no `X | Y` type unions at runtime and no `match` statements. `ada-url` has separate version constraints above and below 3.10 in `pyproject.toml`.
3. **Async tests need `@pytest.mark.asyncio`.** No `asyncio_mode` is set in `pyproject.toml`, so pytest-asyncio runs in strict mode and ignores an unmarked async test. Depending on the pytest version it then fails with an "async def functions are not natively supported" message or is skipped with a warning. If a new async test fails that way or shows as skipped, check the marker first.
4. **Two dependency lists.** `pyproject.toml` + `poetry.lock` drive installs. `requirements.txt` is a hand-maintained copy that only the Snyk SCA workflow reads. Changing one without the other leaves the scan out of date. Today `cryptography` and `jwcrypto` are in `pyproject.toml` but not in `requirements.txt`, so the scan does not see them.
5. **`custom_fetch` covers only discovery and JWKS.** `fetch_oidc_metadata` and `fetch_jwks` (`utils.py`) use the integrator's `custom_fetch` when set. The token endpoint calls in `get_access_token_for_connection`, `get_token_by_exchange_profile`, and `get_client_credentials_token` always build their own `httpx.AsyncClient` with `options.timeout`. Do not assume a new HTTP path inherits either behaviour, pick the matching pattern deliberately.
6. **Imports must be at module top level.** `.ruff.toml` enforces `PLC0415`, so an import inside a function fails `ruff check .`. Move it to the top of the file. For a circular import, use `if TYPE_CHECKING:` as `config.py` does.
7. **Stale local venvs.** A hand-made venv in the working tree (anything other than Poetry's) may not have the package or dev dependencies installed. Use `poetry install` then `poetry run ...` so you test the same environment CI does.
